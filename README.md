# Malakhi Boyce — Portfolio Website

Responsive static portfolio made with HTML, CSS, and vanilla JavaScript for GitHub Pages.

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive layout and visual design
- `script.js` — mobile navigation and automatic footer year

## Publish to GitHub Pages
1. Open https://github.com/mjb632-afk/mjb632.github.io
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `styles.css`, and `script.js` from this folder to the repository root.
4. Commit the files to the `main` branch.
5. Go to **Settings → Pages** and choose **Deploy from a branch**, `main`, and `/(root)`, then Save.
6. After a few minutes, open https://mjb632-afk.github.io/

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with the email you want to publish.
- Replace the LinkedIn placeholder with your real profile URL, or remove that link.
- Confirm experience dates and descriptions are accurate.
- Add links to actual reports, music samples, or project deliverables as you publish them.

The project summaries are intentionally framed as areas of study/work, not as claims that finalized deliverables are already available online.
